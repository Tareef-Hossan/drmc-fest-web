# Screenshots Folder

This folder should contain the following screenshots for the README.md:

1. **fest-directory.png** - Browse all upcoming fests with search and filters
2. **fest-details.png** - View detailed information about each fest
3. **event-registration.png** - Register for events with capacity tracking
4. **user-dashboard.png** - Manage your registrations
5. **admin-dashboard.png** - Overview with statistics and charts
6. **participant-management.png** - Search, filter, and manage participants

## How to Add Screenshots

1. Take screenshots of the application using your preferred tool (Snipping Tool, Lightshot, etc.)
2. Save them in this folder with the exact filenames listed above
3. Update the README.md if you need to change the image descriptions

## Notes

- Screenshots should be in PNG format for best quality
- Recommended size: 1920x1080 or similar widescreen aspect ratio
- Make sure sensitive information (real emails, phone numbers) is not visible

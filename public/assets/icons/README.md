# Icons Needed

This directory should contain the following icon files for PWA support:

## Required Icons

- **icon-72x72.png** - 72x72 pixels
- **icon-96x96.png** - 96x96 pixels
- **icon-128x128.png** - 128x128 pixels
- **icon-144x144.png** - 144x144 pixels
- **icon-152x152.png** - 152x152 pixels
- **icon-192x192.png** - 192x192 pixels
- **icon-384x384.png** - 384x384 pixels
- **icon-512x512.png** - 512x512 pixels

## Favicon

- **favicon.ico** - For browser tab
- **favicon-16x16.png** - 16x16 pixels
- **favicon-32x32.png** - 32x32 pixels

## Design Guidelines

- Use the DRMC IT Club logo
- Background: #1de9b6 (teal) or transparent
- Keep it simple and recognizable at small sizes
- Use the same logo as in assets/images/logo.png

## Tools to Generate Icons

You can use online tools to generate icons from your logo:
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/
- https://www.pwabuilder.com/imageGenerator/

## How to Add Icons

1. Create your logo as a PNG with transparent background
2. Use one of the tools above to generate all required sizes
3. Download and place the files in this directory
4. Update the manifest.json if needed

## Note

For now, the app will work without these icons, but PWA installation will show a default icon.
